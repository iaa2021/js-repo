Great idea! You already have a working Node.js HTTPS chat with mutual TLS (mTLS).
 Now we can turn it into a browser-based chat application using Express, HTML,
  CSS, and Socket.IO.
The browser will display a chat page, users will enter their names, and messages 
will appear in real time without refreshing the page.
I'd recommend Socket.IO because it handles real-time communication, 
reconnections, and message delivery events more conveniently than implementing 
a raw WebSocket server yourself.

4. Build the Express and Socket.IO server
Create server.js:

import express from 'express';
import https from 'https';
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { Server } from 'socket.io';
import { PORT } from './config.js';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const app = express();

const tlsOptions = {
    key: fs.readFileSync('./certs/server-key.pem'),
    cert: fs.readFileSync('./certs/server-cert.pem'),

    // Enable these options if requiring mTLS:
    // requestCert: true,
    // rejectUnauthorized: true,
    // ca: fs.readFileSync('./certs/ca-cert.pem')
};

app.use(express.static(path.join(__dirname, 'public')));

const httpsServer = https.createServer(tlsOptions, app);
const io = new Server(httpsServer);

io.on('connection', (socket) => {
    console.log(`Client connected: ${socket.id}`);

    socket.on('join', (name) => {
        const safeName = String(name).trim().slice(0, 30);

        if (!safeName) return;

        socket.data.name = safeName;

        io.emit('system message', `${safeName} joined the chat`);
    });

    socket.on('chat message', (message) => {
        const name = socket.data.name;

        if (!name || typeof message !== 'string') return;

        const text = message.trim().slice(0, 1000);

        if (!text) return;

        io.emit('chat message', {
            name,
            text,
            time: new Date().toLocaleTimeString()
        });
    });

    socket.on('disconnect', () => {
        const name = socket.data.name;

        if (name) {
            io.emit('system message', `${name} left the chat`);
        }

        console.log(`Client disconnected: ${socket.id}`);
    });
});

httpsServer.listen(PORT, () => {
    console.log(`Chat server listening at https://localhost:${PORT}`);
});



This server uses HTTPS for the browser and Socket.IO for real-time communication.
 The example leaves mTLS disabled initially so you can get the browser application
  working first. We can then enable client-certificate authentication.

6. Add the browser-side JavaScript
Create public/chat.js:

const socket = io();

const joinForm = document.querySelector('#join-form');
const username = document.querySelector('#username');
const chatArea = document.querySelector('#chat-area');
const messageForm = document.querySelector('#message-form');
const messageInput = document.querySelector('#message-input');
const messages = document.querySelector('#messages');
const leaveButton = document.querySelector('#leave-button');

function addMessage(text) {
    const item = document.createElement('li');

    // Use textContent to avoid interpreting messages as HTML.
    item.textContent = text;
    messages.appendChild(item);
    item.scrollIntoView({ block: 'end' });
}

joinForm.addEventListener('submit', (event) => {
    event.preventDefault();

    const name = username.value.trim();

    if (!name) return;

    socket.emit('join', name);
    joinForm.hidden = true;
    chatArea.hidden = false;
    messageInput.focus();
});

messageForm.addEventListener('submit', (event) => {
    event.preventDefault();

    const text = messageInput.value.trim();

    if (!text) return;

    socket.emit('chat message', text);
    messageInput.value = '';
    messageInput.focus();
});

socket.on('chat message', ({ name, text, time }) => {
    addMessage(`[${time}] ${name}: ${text}`);
});

socket.on('system message', (text) => {
    addMessage(`* ${text}`);
});

leaveButton.addEventListener('click', () => {
    socket.disconnect();
    chatArea.hidden = true;
    joinForm.hidden = false;
    username.focus();
});

9. How to add mTLS
Your current terminal application uses client certificates. 
Browser-based mTLS is possible, too, but it changes the setup:
- The browser must have a client certificate installed.
- The server must request and verify client certificates.
- Your CA must sign the client certificates.
- The server should derive the authenticated identity from the verified certificate
 rather than trusting a name supplied by the browser.
For a learning project, I suggest getting the basic browser chat working first, 
then enabling mTLS and testing it with your existing CA.
One security detail: the sample is a learning prototype. Before exposing it to
 a network, add authentication and authorization, rate limiting, message
  validation, and appropriate handling of certificate identity and disconnects.
